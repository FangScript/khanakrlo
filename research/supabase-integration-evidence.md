# Supabase Google Authentication Integration Evidence

Supabase’s official Expo guide describes using `@supabase/supabase-js`, platform storage adapters, protected navigation, and social-authentication flows in Expo React Native applications. Its native mobile deep-linking guide requires an app URL scheme and an allowed Supabase redirect URL. The Google provider guide requires Google Cloud OAuth configuration, provider enablement in Supabase, and platform-specific Google client IDs for native builds.
