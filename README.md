# Khana KarLo

The `zeeshan` branch contains the rebuilt pilot platform under [`v2/`](./v2/).

It follows the documented microservice architecture with independently deployable services, versioned REST and event contracts, separate service databases, a shared React Native app with customer, merchant, and rider workspaces, and a desktop admin console.

Start with [`v2/README.md`](./v2/README.md) for local setup and service commands.
